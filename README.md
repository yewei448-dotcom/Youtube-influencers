# YouTube 达人工作台

本地运行的达人拓展与合作工具，串起找达人、筛选、建联、回信议价、合作复盘和交付提醒。每位使用者的数据保存在自己的电脑；本仓库只提供程序与空白配置示例，不包含业务名单、邮件或凭据，也不自动提供多人数据同步。

## 当前功能

| 入口 | 功能 |
| --- | --- |
| 找达人 | 关键词挖掘、筛选，以及锁定频道的新视频监测；主页与视频可直接打开。 |
| 达人资源 | 历史达人资源、合作记录、人工筛选池、相似达人推荐。支持按频道打标签，沿用标签排除后续关键词与相似推荐，也可复核和恢复。 |
| 建联库 | 联系人管理、发送预览、多发件账号、邮件记录、回信与报价、议价，以及产品和模板编辑。 |
| 数据分析 | 已有合作效果、回复情况、YouTube 数据、可选 GA4 会话和下载数据及热点查询。 |
| 待办提醒 | 查看和处理回信、合作交付等本地待办。 |

合作记录当前只展示本地已有合作效果记录；外部 OA/ORMS API 同步暂停、尚未接入。历史金额与来源可核对，不自动替换本轮报价。已有合作不会自动成为不适合名单，标签与恢复由使用者确认。

## 安装与启动

需要 Python 3.9 或以上版本。依赖清单固定 Streamlit 1.50.0、pandas 2.3.3；安装依赖和访问 YouTube 等服务需要网络。

在项目目录中创建并启用虚拟环境：

```bash
python -m venv .venv
```

macOS / Linux：`source .venv/bin/activate`；Windows PowerShell：`.venv\Scripts\Activate.ps1`。

```bash
python -m pip install -r requirements.txt
```

首次使用时，把 `email_config.ini.example` 复制为 `email_config.ini`，在 `[youtube]` 的 `api_key` 填入自己的 YouTube Data API Key。可选的 `[ga4]` 只在使用 GA4 时填写；服务账号私钥保留在本机。升级时保留已有配置，不用示例覆盖。

从项目目录启动：

```bash
python -m streamlit run youtube_workbench.py
```

## 邮箱、产品与模板

在“管理发件账号”添加自己的邮箱和授权码，分别验证 SMTP 发信与 IMAP 收信。验证只测试登录，不发送测试邮件；授权码保存在操作系统凭据库。需要可用的系统凭据服务，不通过明文文件分享账号。

联系人共享显示；邀约、邮件、回信、报价和议价跟随各自发件账号。先选达人、准备邮件，再选发件账号和匹配模板，预览后明确确认发送。切换账号不会把另一账号的回信或议价草稿带过来；旧邮件需明确确认原账号归属，未归属记录保持只读。

在“建联库 → 模板与产品”新增产品、编辑或还原模板。模板按产品、合作形式和用途精确匹配；缺少模板或必填变量时先补齐。首次邀约让达人报价，不自动带入内部预算或建议价。个人模板保存在本机，修改不影响其他同事。

## 每日频道监测

在“找达人 → 达人自动推送”配置锁定频道和检查时间。默认关注锁定频道的新视频，关键词用于标记或筛选；首次检查建立基线，不把全部历史视频当作新更新。

**打开网页不会自动启动监测后台。** 在同一项目目录、同一虚拟环境的另一个终端中运行：

```bash
python monitor_worker.py --daemon
```

后台持续运行时，才能处理每日计划或页面中的检查请求；只检查一次可使用 `python monitor_worker.py --once`。需要开机、联网及有效的 API Key 和配额。电脑休眠、后台关闭或网络中断时不会保证持续检查；请查看页面的实际运行状态和最后检查时间。仓库不自动安装开机启动任务，也不自动发送邀约。

## 升级与数据保留

1. 正常关闭工作台和监测后台，备份完整旧目录，包含隐藏文件和目录，保证 CSV 与 SQLite 数据库及其附属文件完整。
2. 把新版本先下载到独立目录，核对后仅更新发布的程序、静态资源和依赖清单。保留原目录的个人配置、CSV、数据库、账号目录、模板库、监测设置、标签、布局设置、邮件和同步状态等全部本地文件，不用空白文件或同事的数据覆盖。
3. 在原工作目录安装更新后的依赖，再启动工作台与需要的监测后台。先核对原联系人、邮件记录、合作记录和账号状态。

操作系统凭据库独立于项目目录；换电脑通常需要重新录入授权码。不同人的 CSV 不能直接互相覆盖合并。`.gitignore` 仅防止新增本地文件被误提交，不能清除已经进入 Git 历史的敏感内容。
